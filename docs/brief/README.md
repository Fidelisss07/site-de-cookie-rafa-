# SFORNATI COOKIES — Website Build Pack

Pacote preparado para Claude Code Opus 5.5 / Astra 6 implementar o site da Sfornati Cookies.

## Objetivo
Construir uma experiência premium, artesanal e altamente visual para venda de cookies, evitando aparência de template genérico de delivery.

## Comece por aqui
1. Leia `docs/CLAUDE_CODE_MASTER_PROMPT.md`.
2. Consulte `docs/DESIGN_SYSTEM.md` e `docs/SITE_ARCHITECTURE.md`.
3. Use `assets/reference/04_homepage_visual_direction.png` como referência visual principal.
4. Use as três imagens originais do WhatsApp apenas como fonte de identidade/produto. Não reproduza a interface do WhatsApp no site.
5. Implemente responsivo desde o início.

## Assets incluídos
- `01_logo_reference.jpeg` — referência da logo Sfornati.
- `02_menu_alpino_chocolate_branco.jpeg` — fotos e nomes de Alpino / Chocolate Branco.
- `03_menu_meio_amargo_ao_leite.jpeg` — fotos e nomes de Meio Amargo / Ao Leite.
- `04_homepage_visual_direction.png` — direção visual criada para a home.
