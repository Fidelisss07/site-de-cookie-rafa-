# Design System — Sfornati Cookies

## Personalidade
Premium artesanal + aconchegante + editorial. Evitar visual infantil, excesso de rosa, gradients neon, glassmorphism genérico e cards excessivamente arredondados.

## Cores
| Token | Valor | Uso |
|---|---|---|
| espresso | #160D08 | fundo principal escuro |
| cocoa | #2A140B | superfícies escuras |
| cream | #F6ECDD | fundos claros |
| warm-white | #FFF9F0 | texto/fundo claro |
| caramel | #D79A5B | CTA e destaque |
| soft-gold | #C89B62 | detalhes premium |
| muted-brown | #7C6658 | texto secundário |

## Tipografia
Display serif com contraste alto para headlines. Sans geométrica/humanista para UI. Headline desktop 72–96px quando houver espaço; mobile 44–58px. Corpo 16–18px.

## Grid
Max width 1440px. Conteúdo principal 1200–1320px. Espaçamento generoso. Seções 96–144px desktop e 64–88px mobile.

## Formas
Radius moderado: 16–24px em cards; botões pill apenas quando fizer sentido. Bordas finas e quentes. Sombras discretas.

## Fotografia
Macro, quente, baixa profundidade de campo, textura do cookie evidente, chocolate derretido, fundo escuro ou creme. Evitar stock frio e composição clínica.

## Motion
200–500ms para UI. Hero pode ter reveal de 700–1000ms. Nada de animação contínua chamativa.
